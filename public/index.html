Enterprise Infrastructure Lab

A physical enterprise-style network I built to move beyond simulation: a managed Layer 3 switch, three Raspberry Pi servers, hand-terminated cabling and real client devices.

Repository and configuration files

Physical layer

Cables I prepared and tested myself.

UTP preparation, RJ45 termination, crimping and continuity tests came before any configuration.

Network layer

One switch, three VLANs, routed internally.

The Aruba 2930F JL256A routes between Clients, Management and Servers. DHCP relay carries client requests across the VLAN boundary.

Services

DHCP, DNS and a web server on Raspberry Pi.

ISC DHCP serves the wired client scope. BIND9 answers for the internal lab.home.arpa zone, and Nginx hosts a custom dashboard at web.lab.home.arpa.

Validation

Tested from real devices.

A Windows laptop on VLAN 10 received 192.168.10.50 through DHCP relay. A MacBook administered the switch from the management VLAN.

Implemented

  • VLAN 10 Clients, 99 Management, 100 Servers
  • Layer 3 routing on the Aruba 2930F
  • ISC DHCP with DHCP relay
  • BIND9 internal DNS and Nginx web server
  • Static server addressing, dynamic client addressing
  • Windows DHCP validation, configuration backups

Roadmap, not built yet

  • VLAN 20 wireless and Aruba access point
  • Internet gateway, NAT/PAT
  • Firewall and ACLs
  • Monitoring and logging
  • VPN, IDS/IPS, DMZ

HAN37

Where a web application meets a sensor.

Repository and demo videos
  1. Web application
  2. Node.js · Express
  3. Serial port
  4. Arduino
  5. Temperature / humidity sensor

Users sign in with session-based authentication and bcrypt password checks, then reach a Control Center, a calendar and the Smart Room module. The server reads JSON from the Arduino over USB serial, exposes it at /api/sensor, retries the connection if it drops, and stores data in MySQL.

Node.js, Express, MySQL, express-session, bcryptjs, SerialPort, Arduino, dotenv. Still in development, not a finished product.

Configured and documentedNetworking, Cisco, Packet Tracer

Enterprise Network Design

A simulated company split into IT, Human Resources, Finance and Sales, with Cisco 2911 routers and 2960 switches. The repository includes the exported router and switch configurations, so the design is documented and not only drawn.

Repository and exported configurations

Implemented

  • IPv4 addressing and subnetting for each department
  • VLAN segmentation, 802.1Q trunking, PVST
  • Router-on-a-stick inter-VLAN routing
  • Static routing between the four routers
  • Centralized DHCP with relay, and DNS
  • Management VLANs, SSH, wireless networking

Planned, not implemented

  • OSPF
  • Extended ACLs, broader SSH management
  • Port security, DHCP snooping
  • Firewall integration, NAT, simulated Internet
  • Syslog, NTP, monitoring
